# Руководство администратора

Для администраторов группы (роли `admin` / `administrator`). Управление
юрлицами, ролями и типами заданий доступно в режиме **«Все юрлица»** — его
выбирают в переключателе юрлица в шапке; там же переключаются между
организациями для повседневной работы.

## 1. Вход и рабочие страницы

1. Откройте адрес приложения, войдите логином и паролем.
2. После входа вы попадаете на страницу своего рабочего места
   (`/admin` для Админа, `/administrator` для Администратора и т.д.).
3. Активное юрлицо видно в шапке; если доступно больше одного юрлица — рядом
   селект «Все юрлица» / конкретные организации. После переключения страница
   перезагружает данные.

Пароль: смена пароля любым администратором закрывает все сессии этого
пользователя. Свои действия (вход, выход, смены) фиксируются в журнале.

## 2. Юрлица

Настройки → **«Юрлица группы»** (виден только в режиме «Все юрлица»).

**Создать:** «Название» обязательно, «Короткое имя» и «ИНН» — по желанию.

**Правила:**

- юрлицо нельзя удалить — только выключить (данные и история остаются);
- нельзя выключить последнее активное юрлицо и юрлицо, при выключении которого
  у кого-то из пользователей не останется ни одного активного юрлица;
- список рядом с каждым юрлицем показывает, сколько пользователей, адресов,
  заданий и отчётов к нему привязано.

После создания юрлица выдайте пользователям к нему доступ (раздел
«Пользователи») и при необходимости добавьте адреса — адреса принадлежат
юрлицу, а помеченные «общими» видны всем организациям группы.

## 3. Пользователи и доступ

Настройки → **«Пользователи»**.

**Создать:** логин, пароль, роль. В режиме «Все юрлица» обязательно выберите
юрлицо, в котором пользователь начнёт работу.

**Доступ (кнопка «Доступ» в карточке пользователя):**

- галочками — в каких юрлицах работает пользователь;
- точкой — его основное юрлицо (куда он попадает после входа);
- роль — единая для всех его юрлиц.

Пароль пользователя меняется кнопкой «Сменить пароль» — после этого все его
сессии закрываются. Увидеть и отредактировать можно только пользователей в
области вашего доступа: в сводном режиме — всех, в конкретном юрлице — только
его пользователей.

## 4. Роли и возможности

Настройки → **«Роли и возможности»**.

Роль определяет: какие действия доступны (возможности), какая страница
открывается после входа (рабочее место) и какие данные видны
(«всё юрлицо» или «только свои» записи).

- **Системные роли** (`Админ`, `Сервис`, `Директор`, `Экипаж`, `Руководитель`,
  `Бригада`, `Администратор`, `Куратор`) изменять нельзя — они воспроизводят
  привычное поведение. Любую из них можно **скопировать** и настроить свою.
- **Своя роль:** название, код (латиницей), рабочее место, область данных и
  галочки возможностей. У возможности всегда есть реализация в приложении.
- Роль, назначенную пользователям, нельзя выключить — сначала смените им роль.

Справочник возможностей (сокращённо):

| Группа | Возможности |
|---|---|
| Мониторинг | отправлять мониторинг, комментировать мониторинг и ленту, смотреть мониторинги юрлица |
| Задания | создавать, писать сообщения, прикреплять файлы, отправлять на проверку, принимать, возвращать на доработку, закрывать, править |
| Экипаж | отправлять отчёты, смотреть свои отчёты, смотреть и комментировать отчёты Экипажа |
| Прочее | Excel-выгрузка, скрывать записи ленты, настройки и квоты, пользователи, юрлица, роли, типы заданий, переходы |

## 5. Переходы заданий (workflow)

Настройки → **«Переходы заданий»**.

Статусы заданий фиксированы:

```text
открыто → на проверке → принято / на доработке → закрыто
```

Для каждого перехода галочками отмечены возможности, любой из которых
достаточно, чтобы его выполнить. Значения по умолчанию:

| Переход | Возможность по умолчанию |
|---|---|
| Отправить на проверку (открыто/на доработке → на проверке) | «отправлять задание на проверку» |
| Принять задание | «принимать задания» |
| Вернуть на доработку | «возвращать на доработку» |
| Закрыть задание | «закрывать задания» |

Пример: если у перехода «Отправить на проверку» оставить только возможность
«принимать задания», отправлять задания на проверку смогут роли с этой
возможностью (например, проверяющие), а исполнители — нет. Изменения
применяются сразу, перезапуск и перелогин не нужны.

## 6. Типы заданий

Настройки → **«Типы заданий»**.

Тип добавляет в форму создания задания до 5 дополнительных полей:
текст, число, дата или список (для списка задаются варианты). Поле может быть
обязательным — без него задание не создастся.

- Тип «Обычное задание» системный: без доп. полей, как раньше.
- У типа, который уже используется в заданиях, состав полей не меняется —
  создайте новый тип, чтобы не потерять смысл заполненных карточек.
- Выключенный тип исчезает из форм создания, существующие задания остаются.

В карточках ленты и списке задач, а также в Excel-выгрузке показываются тип и
заполненные значения полей.

## 7. Настройки загрузки медиа

Настройки → «Общие настройки» и «Квоты и хранилище»:

- включение/выключение загрузки фото и видео;
- лимит на файл (фото/видео) и общая квота хранилища; `0` снимает настраиваемый
  лимит, технический предел — 100 MiB на файл;
- отображается занятое место и превышение квоты.

## 8. Что записывается в журнал

`audit_log`: вход, неудачный вход, вход заблокированного, выход, смена пароля,
создание пользователя, смена доступа к юрлицам, изменения юрлиц и ролей,
настройки и квоты, создание заданий и их переходы, скрытие записей ленты,
переключение юрлица. Посмотреть журнал можно SQL-запросом (см.
`app/DEPLOYMENT.md`).

## 9. Частые вопросы

**Смена рабочей страницы роли.** У каждой роли есть «рабочее место»
(сервис / лента и проверка / экипаж / руководитель / администратор) — страница
определяется им, поэтому у своей роли выберите рабочее место, похожее на
задачи пользователей.

**Пользователь «потерял» данные.** Проверьте его активное юрлицо (данные
разных юрлиц изолированы) и область данных роли («только свои» показывает лишь
собственные записи).

**Нужно закрыть доступ человеку.** В карточке пользователя смените пароль (это
закроет все его сессии) или выключите пользователя; для точечной настройки —
уберите ненужные юрлица из его доступа.
